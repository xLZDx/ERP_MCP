Result

DONE in the test lane. accounting_balance_by_analytics for account 521.1 now answers from a profile validated by ten machine two-source cases and says so in every response. The answer equals the hand-written 1C query exactly (2026-08-31). Nothing else was unlocked.

What this is not

  • It is a cross-copy comparison of two machine runs, not parity proof and not a human native 1C report (ADR-0008 section 8). Responses carry VALIDATED_MACHINE_RECONCILED and the warning MACHINE_RECONCILED_NOT_HUMAN_NATIVE_REPORT.
  • Test environment only; production refuses the allow-list at startup. One source, one concept, one account (521.1).
  • All other tools (payable_balance, accounting_balance_and_turnovers, ...) still refuse: no validated profile. No source-wide grant was given to user_company_one.
  • A live ChatGPT call after the restart is not part of this evidence (the operator can make one system_status call).

Real defects found and fixed

Capability fingerprint included discovered_at
Any profile on a live source became stale at the next probe ("capability evidence changed"). Found by the live call. Fixed with one shared function at five sites; regression test added; fixtures without the stamp keep the same value.
Case normalisation dropped the evidence class
A machine profile would have read back as native. Found by the PostgreSQL chain test before the lane run. The CLI now stores the full verified case records.
Side-A references through COM
The first lane run produced one empty-reference row per case. Fixed in the private lane script (XMLString of the reference); the repository code was not affected.

Lane evidence (private artifacts, no business names or amounts here)

  • Ten month-end cases 2025-11-30 .. 2026-08-31; side A = hand-written 1C query through COM on a disposable clone, side B = production tool code; 10 of 10 identical in exact decimals on key (counterparty, contract, currency).
  • Profile validated by scripts/semantic_profiles.py validate: artifacts re-read (digest, embedded run id and method, no truncation), approved Rosetta plan checked.
  • Lane gateway restarted with BAG_MACHINE_RECONCILED_SOURCES=onec-818ha-reference; HTTP call as user_company_one: labelled machine-reconciled, 10 aggregated rows equal to the 1C query.
