# Плагин ERP_MCP_REAL1 в ChatGPT: как пользоваться после восстановления

Это тестовый стенд: данные только для чтения, база 818 HA SRL. Плагин ничего не меняет в 1С.

## 1. Что работает сейчас

| Что спросить | Результат |
|---|---|
| «Покажи статус ERP_MCP» | работает |
| «Какие источники доступны?» | работает: реальный `onec-818ha-reference` и отдельно помеченный синтетический портфель |
| «Какие компании в источнике onec-818ha-reference?» | работает: 818 HA SRL |
| «Проверь здоровье источника», «какие возможности у источника», «найди справочник Контрагент» | **сейчас недоступно вашей учётке** (см. раздел 3) |
| Остатки, обороты, проводки, кредиторка, возрастной анализ по реальной компании | **сейчас закрыто защитой**: ответ «профиль не подтверждён» (см. раздел 4) |

## 2. Как задавать вопросы

Всегда называйте источник `onec-818ha-reference`, а компанию берите из списка компаний. Даты пишите явно:
«на 31.08.2026», «за август 2026». Плагин сам переводит их в нужный формат.

Пример, который заработает после подтверждения профиля:
«Сколько мы должны каждому поставщику по счёту 521.1 на 31.08.2026? Дай таблицу: поставщик, счёт, дебет, кредит, к оплате, и итог».

## 3. Если ответ «Error executing tool …» на проверку источника

Для вашей учётки выданы права на компанию, а не на весь источник. Проверка здоровья, список возможностей и поиск
по метаданным требуют права на источник целиком. Это сделано намеренно, чтобы компания не видела устройство чужих данных.
Если такие вызовы нужны именно вам, попросите администратора выдать право на источник (это его решение).

## 4. Если ответ «SEMANTIC_PROFILE_UNVALIDATED» или «профиль не подтверждён»

Плагин не знает, какие счета и аналитики считать поставщиками, пока владелец данных не подтвердил это сверкой с
отчётами самой 1С (нужно не меньше десяти настоящих отчётов). Пока профиль не подтверждён, плагин **не выдаёт цифр**,
а не показывает ноль. Это правильное поведение: ноль выглядел бы как настоящий ответ.

Что сделать: передать владельцу данных просьбу подготовить отчёты из 1С для сверки. Подготовка профиля идёт в панели администратора.

## 5. Если плагин вообще не отвечает

1. Откройте `http://127.0.0.1:21000/healthz` на компьютере со стендом: должно быть `200`.
2. Если нет, администратор перезапускает шлюз одной командой из папки `D:\Repo\ERP_MCP-integration-candidate`:

   ```powershell
   $env:E2E_DIR = 'D:\ERP_MCP_Testbed\real1c_e2e'
   $env:E2E_REAL1C = '1'
   .\scripts\e2e\fault.ps1 -Component gateway -Action restart
   ```

   Скрипт сам подставит доступ читателя 1С и не остановит рабочий шлюз, если подставить его не получится.
3. Если вход в ChatGPT просит авторизацию, повторите подключение плагина: тестовый вход работает через временный адрес Cloudflare, он может смениться после перезапуска туннеля.

## 6. Что плагин не делает

Не создаёт и не меняет документы, не показывает пароли, не отвечает по чужим компаниям. Тестовые данные синтетического портфеля
не смешиваются с реальной компанией: у них отдельная пометка в списке источников.
