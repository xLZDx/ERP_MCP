## Scope decision

S5 is P0 and large. This sprint takes the four stories that can be built and tested offline as reference modules with no UI, no real storage and no real 1C: US-024 (permit), US-025 (side-effect boundary), US-026 (artifact vault), US-027 (parser isolation). US-021 (manual native UI baseline with manifest/attestation) and US-022 (UI automation of the native interface) need a real UI and the vault + parser; they are deferred to S5b and stay NOT_STARTED. Operator-dependent items (real 1C UI, accountant attestation, OAuth) stay with the operator.

## Epics, stories, Definition of Done, tests

| Epic | Story | Module (new files) | DoD | Tests (requirement -> assertion) |
| --- | --- | --- | --- | --- |
| E1 | R2-US-024 bounded capture permit (REQ15, 26) | `src/business_ai_gateway/phase2/capture_permit.py`, `tests/phase2/test_capture_permit.py` | A permit is issued by a data owner for ONE (tenant, source) scope, a time window, a mode and a parameter digest. Admission checks scope, window and mode on every use. Production is default OFF: a production permit is refused unless explicitly enabled by policy, and an expired or not-yet-valid permit is denied. The same idempotency key with different parameters is a conflict (HTTP 409 equivalent `IDEMPOTENCY_CONFLICT`), the same key with the same parameters replays the first result. Issuer must differ from the requester and must be a human owner. | TC070 a permit admits only its scope, window and mode (each of the three violated alone is denied); TC071 production without the policy flag denied, expired denied, not-yet-valid denied, boundary instants exact; TC072 same key + same params replays, same key + different params -> conflict, nothing created |
| E2 | R2-US-025 side-effect boundary (REQ15) | `src/business_ai_gateway/phase2/side_effect_boundary.py`, `tests/phase2/test_side_effect_boundary.py` | A capture plan is a list of declared operations. Only read-class operations are allowed; any write, post, delete, reset, admin or unknown operation disqualifies the plan (fail closed). A plan that requires administrator or posting rights is disqualified. Reset and write probes are denied in production. The result carries a coverage statement: every declared operation is classified, an unclassified operation is a denial. | TC073 a read-only plan passes and its coverage lists every operation, an unclassified operation denies; TC074 a plan requiring admin/posting rights is disqualified; TC075 reset and write-probe operations are denied in production and never promoted to allowed by name tricks (case, whitespace, homoglyph) |
| E3 | R2-US-026 immutable private originals (REQ16, 17) | `src/business_ai_gateway/phase2/artifact_vault.py`, `tests/phase2/test_artifact_vault.py` | An in-memory content-addressed vault: put returns an opaque version id bound to the SHA-256 of the bytes; versions are immutable (a second put of the same bytes is idempotent, different bytes never overwrite). Evidence is valid only if the blob exists AND the digest matches; a reference to a nonexistent blob or hash is not evidence. Reads check the CURRENT ACL of the reader against the artifact scope, also for historical versions. | TC076 version id is opaque and tied to the digest, rewriting is impossible; TC077 nonexistent blob / wrong hash / hash-only claim is not evidence; TC078 after the ACL is revoked a historical version is no longer readable by that reader, other scopes never see it |
| E4 | R2-US-027 parser isolation (REQ17) | `src/business_ai_gateway/phase2/safe_parser.py`, `tests/phase2/test_safe_parser.py` | A values-only XLSX/CSV reader for untrusted files, run with hard bounds: no formulas evaluated (values only), macros (vbaProject), external entities/DTDs, external links and zip bombs (compression ratio, member count, uncompressed size) are denied; time and memory bounds produce an explicit failure, never a truncated PASS. Pure stdlib (zipfile + defusedxml-free hardened parsing with entity rejection); optionally runs in a child process with a timeout. | TC079 a normal workbook yields cell values only (a formula cell yields its cached value or none, never evaluated); TC080 macro / DOCTYPE or entity / zip bomb / external link are denied with fixed codes; TC081 an input over the byte/row/time bounds fails with a bound code and no partial rows are returned as success |
